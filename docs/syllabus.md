# Syllabus

## Tutorial goals

- Introduce the fundamentals of GPU-accelerated data science and the RAPIDS ecosystem.
- Perform accelerated data loading, cleaning, and feature engineering workflows.
- Apply GPU-based machine learning methods in practical notebook exercises.
- Highlight scalable experimentation and performance-aware workflows.
- Give attendees reusable materials they can continue working with after the tutorial.

## Intended audience

This tutorial is aimed at intermediate-level students, researchers, and practitioners in data science, AI, and scientific computing.

## Prerequisites

- working knowledge of Python
- familiarity with pandas, NumPy, and basic machine learning concepts
- a laptop with internet access

## Format

Half-day, hands-on tutorial with guided theory segments and notebook-based exercises.

## Detailed schedule

| Session | Topic | Duration | Details |
| --- | --- | ---: | --- |
| 0 | Environment setup | 20 min | Access to GPU resources, notebooks, datasets, and the tutorial workflow |
| 1 | GPU data science fundamentals | 60 min | GPU concepts, RAPIDS overview, data loading and manipulation, CPU vs GPU comparisons |
| - | Break | 15 min | Short break |
| 2 | Machine learning on GPUs | 65 min | GPU-accelerated ML concepts, hands-on model training, evaluation, and workflow scaling |
| 3 | Graph analytics with cuGraph | 40 min | Graph use cases, graph construction, and graph algorithms on GPUs |
| 4 | Wrap-up and Q&A | 10 min | Final discussion and next steps |

## Learning outcomes

By the end of the session, participants should be able to:

- explain the role of GPUs in modern data science workflows
- identify core RAPIDS libraries and their use cases
- run and adapt the provided notebooks in a cloud environment
- compare CPU-style workflows with GPU-accelerated alternatives
